# 灵敏度调校助手 · Sens Tuner

**为《无畏契约：源能行动》（VALORANT Mobile）玩家打造的个性化灵敏度工具**

测量你的滑屏与陀螺仪操作习惯 → 全自动计算一套最适合你的灵敏度数值 → 对照清单手动填入游戏

</div>

## ✨ 为什么做这个 App？

手游 FPS 的灵敏度没有一个"最佳值"——它取决于**你的手速、滑动习惯、持机稳定性与打法风格**。抄别人的高灵敏度未必适合你，手调又费时费力。

本工具不做玄学推荐，而是**现场测量你的真实操作**：

- 📱 **滑屏测试**：按你平时转视角的习惯快速滑动，采样手指速度曲线
- 🌀 **陀螺仪测试（可选）**：通过手机陀螺仪测量你的转动手腕幅度与稳定度
- 🧠 **推荐引擎**：手速 × 稳定度 × 你选择的打法风格 → 计算出整套灵敏度系数
- 📋 **一键复制清单**：滑屏 / 开火 / 陀螺仪三套 × 各武器开镜档位，全部对应游戏内设置项

**合规**：本工具只做「测量 → 计算 → 展示数值」，所有参数由你手动填入游戏设置。不读游戏内存、不模拟触控、不与游戏进程交互。

1. 克隆本仓库，`flutter pub get`

4. 或使用仓库内的 GitHub Actions（[`.github/workflows/build-ios.yml`](.github/workflows/build-ios.yml)）在 macOS runner 上构建

## 🚀 使用流程（约 1 分钟）

| 步骤 | 操作 |
|---|---|
| 1️⃣ 校准 | 「校准」页在滑动区像游戏里那样划 6 次（滑屏测试）；按住陀螺仪按钮转动手腕 6 段（可选） |
| 2️⃣ 选风格 | 稳架枪 / 均衡 / 激进跟枪，选最接近你的 |
| 3️⃣ 生成推荐 | 点「生成我的灵敏度推荐」，查看数值与理由 |
| 4️⃣ 填入游戏 | 复制清单 → 游戏内「设置 → 操作设置」逐项对照填写 |
| 5️⃣ 微调反馈 | 训练场试枪后，可把推荐存为自定义预设反复对比，越用越准 |

## 📐 灵敏度体系说明

《无畏契约：源能行动》的灵敏度是**三套并行体系**，本工具完整覆盖：

| 体系 | 含义 | 适配武器/档位 |
|---|---|---|
| 滑屏灵敏度 | 手指滑动的镜头转动速度 | 腰射、各枪开镜、冥驹二段开镜… |
| 开火灵敏度 | 开火状态下镜头灵敏度（压枪防抖） | 同上 |
| 陀螺仪灵敏度 | 转动手机的镜头灵敏度 | 垂直 / 转向 + 各枪开镜 |

> 数值参考公开社区实测帖（7724 游戏网 2025-08 攻略）整理，滑块范围以游戏内实际为准。陀螺仪按需开启，部分机型硬件不支持。

## 🧠 推荐引擎原理

```
滑屏采样(速度/距离/稳定度) ─┐
                            ├→ 特征 → 规则引擎 → 推荐系数(look/fire/gyro)
陀螺仪采样(峰值/轴分布/稳定) ─┘         ↑
风格选择(稳架枪/均衡/激进) ─────────────┘
```

**核心规则（可解释、可调）**：

- 滑得**慢** → 调高滑屏灵敏度以弥补手速；滑得**快** → 调低防过度转向
- 手**不稳**（滑动速度离散度高）→ 略微降低换取可控
- 陀螺仪转得**猛** → 降灵敏度防抖；转得**稳** → 适合陀螺仪微调（并建议开启）
- 风格倾向激进 → 陀螺仪推荐权重更高

推荐引擎位于 `lib/logic/calibration.dart`，规则参数全部集中可改，欢迎 PR 优化。

## 🗂️ 项目结构

```
lib/
├── main.dart / app.dart      # 入口、主题（VALORANT 暗色 × 红 #FF4655）
├── theme.dart                # 全局配色
├── models/
│   └── sensitivity.dart      # 数据模型：SensId × SensFamily × WeaponSlot / 预设结构
├── data/
│   ├── presets.dart          # 内置方案库（社区数值整理）
│   └── store.dart            # 本地持久化（SharedPreferences，纯本地无网络）
├── logic/
│   └── calibration.dart      # 采样统计模型 + 推荐引擎（核心算法）
├── state/
│   └── app_state.dart        # 全局状态（ChangeNotifier）
└── pages/
    ├── home_page.dart        # 首页流程引导
    ├── calibrate_page.dart   # 滑屏/陀螺仪采样交互
    ├── recommend_page.dart   # 推荐结果 + 复制清单
    ├── presets_page.dart     # 预设库（内置 + 自定义）
    └── about_page.dart       # 说明 / 合规声明
```

**技术栈**：Flutter (Dart) · sensors_plus（陀螺仪）· shared_preferences（本地存储）
**平台**：Android / iOS 双端

## 🔒 隐私与合规

- 全部数据只存手机本地，**无任何网络请求、无账号、无广告**
- 仅当用户点击陀螺仪校准时读取运动传感器（iOS 会弹 `NSMotionUsageDescription` 说明）
- 本工具与 Riot Games、腾讯互娱**无任何隶属关系**；游戏数值以游戏内实际为准
- 请勿以任何自动化方式操作游戏（外挂/宏），腾讯手游接入 ACE 反作弊，违规将导致封号
